## 本ディレクトリの目的
現在はNextjsでのアプリの運用を行い、デプロイについてもvercelを利用している。
しかしながら、本アプリが広島大学のもとで管理運営される際に、
サーバーを自前で用意するということがあった場合に、スムーズな移行をおこなうため、
サーバーの機能を独立したフォルダに集約させる。

## 対応領域
apps/web配下
    突貫でプロジェクトを作成してしまっているため、機能移行は段階的に行っていく。
    そのため、現段階では(client)で使用する部分の機能を集約させる。
