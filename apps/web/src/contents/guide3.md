# 利用の際の諸注意
- 天候や道路状況などにより、遅れることがあります
- また、安全な運行ができないときは運行を取りやめる場合があります
- おまるめ山バスの乗車定員は8名です。定員を超えての乗車はできません
- 予約はできませんので、ご注意ください
- 運転士は乗降の介助ができません
- また、大きな荷物は載せられません
- 点検などの理由で違う車両で運行する場合があります
- 詳しい運行状況については白市交通へお問い合わせください
