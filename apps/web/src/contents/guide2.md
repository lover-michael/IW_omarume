# 乗り方ガイド
バス停がある区間・フリー乗降区間で利用方法に違いがあります。また、バス停でなく案内板のあるところでも乗り降りすることが出来ます。
### (1)バスを待つ
バス停がある区間:バス停近くの安全な場所で待つ
フリー乗降区間 :運行通路上の安全な場所で待ち、バスが見えてきたら手をあげて運転手に合図する
### (2)バスが停まって、スライドドアが開いたら乗る
### (3)乗車時に運転士に運賃を払い、降りたい場所を伝える
バス停名が分からない場合も、「○○集会所の近くまで」などとお伝えください
### (4)降りる場所が近づいたら、運転士に声をかける
例）乗車時：「○○集会所の近くまで」→降車時：「集会所を過ぎたところで降ろして」
また、車内に降車ボタンは無いのでお声がけください
### (5)バスが完全に停まってから席を立ち、スライドドアが開いたら降りる
